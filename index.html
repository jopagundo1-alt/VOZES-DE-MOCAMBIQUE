# 🇲🇿 ALM — Atlas Linguístico de Moçambique (Versão 2) > “Mapear as línguas. Preservar as vozes.” A **Versão 2** do Atlas Linguístico de Moçambique evolui de uma página estática de demonstração para uma **plataforma colaborativa real**, permitindo recolha descentralizada, registo de variantes regionais, arquivo sonoro nativo e moderação científica. --- ## 🚀 O que muda na Versão 2 1. **Mapa Linguístico Interativo:** Navegação por províncias moçambicanas com detalhe de distribuição de falantes. 2. **Dicionário Colaborativo:** Consulta de termos com estados de validação (`Pendente`, `Em análise`, `Verificado`). 3. **Sistema de Correção & Histórico:** As contribuições antigas não são apagadas; o sistema preserva o histórico de versões e variantes locais. 4. **Arquivo Sonoro Nativo:** Simulação de gravação e reprodução de áudio de pronúncias, saudações e provérbios. 5. **Painel de Moderação:** Interface dedicada para validadores e administradores aprovarem ou solicitarem esclarecimentos sobre novos termos. --- ## 🛠️ Tecnologias Utilizadas * **HTML5 & Tailwind CSS** (via CDN) para uma interface limpa, moderna e responsiva. * **JavaScript (Vanilla)** para gestão de estado local, simulação de formulários, gravação e moderação em tempo real. * *Pronto para integração com o Supabase* (Base de dados relacional e autenticação). --- ## 📦 Estrutura do Projeto ```text atlas-linguistico-mocambique-v2/ │ ├── index.html # Interface completa (Mapa, Dicionário, Formulário, Moderação) ├── style.css # Estilos customizados e animações ├── script.js # Lógica de interatividade e dados simulados └── README.md # Documentação do projeto
